**Как выполняется программа:**
- Каждой функции в скомпилированном коде соответствует отдельная секция
- Адрес начала секции - адрес функции
- Телу функции соответствует  последовательность последовательность команд процессора
- Работа с данными происходит на уровне байт, информация о типах отсутствует 
- В процессе выполнения адрес следующей инструкции хранится в специальном регистре процессора IP(Instruction Pointer)
- Команды выполняются последовательно, пока не встретится специальная команда, которая изменит IP

- на этапе компиляции объектных файлов в места вызова функций подставляются имена функций
- На этапе линковки вместо имен функций подставляются их адреса
- Ошибки линковки 
	- unfefined reference - функция имеет объявление, но не имеет тела
	- multiple definition - функция имеет два и более определения

**Стек вызовов** 
Сегмент данных, используемый для хранения локальных переменных и временных значений
- у стека можно обратиться к произвольной ячейке
- выделяется при запуске программы
- обычно небольшой по размеру (4 мб)
- функции хранят свои локальные переменные в стеке
- при выходе из функции, соответствующая область стека объявляется свободной
- промежуточные значения, возникающие при вычислении сложных выражений, также хранятся на стеке

**Вызов функции**
- При вызове функции на стек складываются 
	- аргументы функции
	- адреса возврата
	- значение frame pointer и регистров возврата
- Резервируется место под возвращаемое значение
- Параметры передаются в обратном порядке, что позволяет реализовать функции с переменным числом аргументов
- адресация локальных переменных функции и аргументов функции происходит относительно frame pointer
- конкретный процесс вызова зависит от используемых соглашений (cdecl, stdcall, fastcall, thiscall)
**Выделение динамической памяти в стиле С**
- библиотека *cstdlib* - предоставляет 4 функции управления динамической памятью
	- void * $*$malloc( size_t size)* - выделяет область памяти размера >= size
	- void *free (void *ptr)* - освобождает область памяти, ранее выделенную  одной из функций malloc/calloc/realloc
	- void *$*$ calloc(size_t nmemb, size_t size)* - выделяет массив из nmemb размера size. Данные инициализуруются 0
	- void *$*$ realloc (void *ptr, size_t size)* - изменяет размер области по указателю ptr на size (если возможно, то это делается на месте)
size_t - специальный целочисленный беззнаковый тип, может вместить в себя размер любого типа в байтах (используется для указания размеров типов данных, индексации массивов и тд)
void * - указатель на нетипизированную память 

**Выделение памяти в стиле С++**
- new и delete - для одиночных значений
- new [] и delete [] - для массивов
- версия delete должна соответствовать версии new
